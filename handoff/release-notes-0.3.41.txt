应用内直接下载并安装更新，并修复上一版发布后的遗留问题。

- **应用内更新**：设置 → 检查更新 发现新版本后，点「下载并安装」即可在应用内下载安装包（带进度），校验文件大小与 SHA-256，随后自动启动安装程序并退出应用，无需再打开浏览器。
- **更新检查更稳**：15 秒超时、自动跟随仓库重定向、网络失败自动重试一次，失败时显示具体 HTTP 状态，便于判断是网络还是接口问题。
- 转码设置（输出格式、MP3 码率）已移到「本地转码」页面，修改后立即保存，下载与转码共用。
- 继承 0.3.40 的全部内容：Qt 新界面默认、深色模式、窗口记忆、完成通知、歌单追更、去重审阅、网易云 Cookie 登录与 eapi 修复、网络代理与出口检测。

已知限制：网易云媒体 CDN 会对海外 IP 返回 403（登录与曲目解析正常，下载需国内网络或代理）；部分曲目受版权或会员限制不可用；抖音仍为官方浏览器保存后导入。

验证：完整安装包隔离检查全绿（含更新检查、安装包地址解析、下载失败提示、代理与出口检测、Qt 与 Tkinter 两套界面）。
